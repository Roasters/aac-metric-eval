# Configurations

`camera_ready.yaml` is the canonical experiment configuration. Relative paths are
resolved from the repository root. `CLOTHO_ROOT`, `AUDIOCAPS_ROOT`, `RESULTS_DIR`,
and `CAF_SRC` override the corresponding local defaults.

Do not change the synonym filters, selector, random seed, or expected counts when
reconstructing the camera-ready tables. Copy the file under a new name for ablations.
